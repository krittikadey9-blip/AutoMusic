# AutoMusic

AutoMusic is a simple Android music player application built using **Kotlin** and **Android Studio**.

The app allows users to select a music file from their device and play it directly through the application.

## Features

- Select music from your device
- Play the selected music
- Music playback in the background
- Simple and beginner-friendly Android UI
- Lightweight Android application

## Technologies Used

- **Kotlin**
- **Android Studio**
- **Android SDK**
- **MediaPlayer**
- **XML Layouts**

## App Interface

The application contains a simple home screen with:

- **AutoMusic** title
- A short description
- **Choose Music** button
- Music selection and playback functionality

## How It Works

1. Open the AutoMusic application.
2. Tap **Choose Music**.
3. Select an audio file from your device.
4. The selected music starts playing.
5. The music can continue playing in the background.
